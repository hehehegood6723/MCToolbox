ZeroTier · 加入网络

              

                Network ID 是什么、去哪拿？

                它不是账号也不是密码。你要先去 my.zerotier.com 免费注册，点「Create A Network」自己创建一个虚拟局域网，网站会分给这个网络一串 16 位十六进制编号 —— 那就是 Network ID。
              

              

                
                
              

              

                
                
              

              

            


            

              
Tailscale · 安装 / 启动 / 登录

              

              

                
                
                
              

              

                必须先装客户端 + 在浏览器里登录成功，Tailscale 才会分配 100.x.x.x 的虚拟 IP；
                没装就点「启动并登录」就会提示「未检测到 Tailscale」。
